# Animal Detection

Animal detection in python using YoLo.

The wild animal attacks are frequent in forests of Kerala. Built a threat detection and alert system with camera and other sensors which detects wild animals and alert the neighbourhood.

This is the ML code used in it. Collected 10k image samples of Elephant, Lion, Tiger, Bear, Wild Boar, Buffalo and labeled them manually using roboflow. Trained the model with Nvidia 4060 GPU.
